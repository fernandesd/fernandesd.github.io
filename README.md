# Diego Fernandes — Portfólio

Portfólio pessoal de Diego Fernandes, Desenvolvedor Backend PHP | Laravel Pleno.

🔗 **Site:** https://fernandesd.github.io/

## Tecnologias

- HTML5 semântico
- Tailwind CSS (via CDN)
- JavaScript Vanilla
- Google Fonts (Inter)

## Deploy (GitHub Pages)

1. Crie um repositório chamado `fernandesd.github.io`
2. Faça push deste código para o branch `main`
3. Acesse **Settings → Pages → Source: Deploy from branch → main / (root)**
4. Aguarde alguns minutos e acesse `https://fernandesd.github.io/`

## Estrutura

```
/
├── index.html      # página principal com todas as seções
├── robots.txt      # permite indexação pelos crawlers
├── sitemap.xml     # mapa do site para SEO
└── README.md       # este arquivo
```
